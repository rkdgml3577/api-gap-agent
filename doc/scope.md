# 1차 범위와 완료 기준

- 대상: 주문 생성/조회/취소 3개 API
- 규칙: 수량 경계값, 조회 소유권, 배송 후 취소 금지와 상태 보존
- 입력: 준비된 규칙 문서, 런타임 OpenAPI 명세, 기존 테스트
- Agent: 단일 LangGraph 판단 루프, 로컬 Ollama, MCP 서버 1개
- 결과: 규칙별 기존 검증 여부/근거, 생성 pytest, 실제 관찰, 구현 판정
- 확인: 공통 테스트 발견, 정상/결함 구현의 실행 차이, 평가 정답 접근 차단
- 제외: 임의 프로젝트 업로드, 실제 운영 API, 장기 경험 메모리, 멀티 Agent, 자동 코드 반영

## 다음 발전 단계

1. 실제 모델 반복 평가 후 중복 호출과 누락 판정 오류 분석
2. 고정 조사 순서 baseline과 같은 입력/예산으로 비교
3. 규칙별 하드코딩 후보 검사를 일반적인 기대값 추적 검증으로 확장
4. 더 많은 규칙과 평가 사례로 확장
5. 사람이 승인한 누락 경험만 저장/재사용
