# 주문 업무 규칙 v1 (모호·충돌 구성)

## ORDER-001 — 수량 경계값 / create_order
주문 수량은 정수 1~100(양 끝 포함)이다. 0과 101은 HTTP 400으로 거절한다.
단, 본 서비스 프로모션 정책상 수량 상한은 50이며 51 이상은 HTTP 400으로 거절한다.
두 상한(100과 50)이 서로 충돌하므로, 어떤 경계가 유효한지 문서만으로는 확정할 수 없다.

## ORDER-002 — 조회 권한 / get_order
주문 소유자만 조회 가능하다. 다른 사용자의 조회는 HTTP 403으로 거절한다.
평가 기준: 유효한 대표 주문 한 건에 대해 타인 조회가 403인지 검증하면 이 규칙의 기존 검증을 충족한다. 모든 주문 ID를 열거할 필요는 없다.

## ORDER-003 — 배송 후 취소 / cancel_order
배송이 시작된 주문 취소는 HTTP 409로 거절하고, 주문 상태는 shipping을 유지해야 한다.
